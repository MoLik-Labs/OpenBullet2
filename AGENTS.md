# Repository investigation

Use [LeanREA](.agents/skills/leanrea/SKILL.md) as the primary investigation guide. For this source checkout, start with source, manifests and existing tests; inspect shipped artifacts only when the question needs them. Treat example commands as references, not an installation or execution checklist. Use local copies and synthetic data; do not expose credentials or use production targets.

Separate observations, inferences and unknowns. Cite a path and symbol for source findings. For runtime or performance claims, record the command, environment and result. If a tool is missing, say what was not verified. Before a migration, define the compatibility test, acceptance metric and rollback point. See the [web modernization plan](docs/web-modernization.vi.md).
